• User Properties
    • User ID
      Randomly generated ID used to identify a Heap user.
    • Identity
      Identity of associated user.
  • Session Properties
    • Session ID
      Randomly generated ID used to identify a Heap user session.
    • Referrer
      Webpage that linked to your site and initiated the session. If the user navigated directly to your site, or referral headers were stripped, then this value will appear as direct.
    • Full Referrer
      Like "Referrer", but also contains the protocol, port, and path if they exist.
    • UTM Source
      UTM parameter attributing the source for the user's session.
    • UTM Medium
      UTM parameter attributing the medium for the user's session.
    • UTM Term
      UTM parameter attributing the keyword for the user's session.
    • UTM Content
      UTM parameter attributing the campaign content for the user's session.
    • UTM Campaign
      UTM parameter attributing the campaign for the user's session.
    • Source
      Where this event came from.
    • App Name
      Name of the app.
    • App Identifier
      Bundle identifier of the app.
    • App Version
      Version of the app.
    • Landing Page
      First page of the user's session.
    • Landing Page Query
      Query parameters of the first page of the user's session
    • Landing Page Hash
      Hash route of the first page of the user's session
    • Browser
      User's browser name.
    • Device Type
      User's device type - "Mobile", "Tablet", or "Desktop"
    • Device
      User's device name.
